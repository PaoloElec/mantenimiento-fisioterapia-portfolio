# 🛠️ Portafolio Analítico: Mantenimiento y Servicio Técnico de Equipos de Fisioterapia

## 📌 Contexto del Proyecto
Este repositorio contiene un caso de estudio enfocado en la gestión operativa, análisis de estacionalidad y optimización de inventarios en el sector de equipos de fisioterapia y electromedicina. El proyecto resuelve problemáticas reales de taller mediante modelado de datos, Python y Business Intelligence (Power BI).

---

## 📂 Estructura del Repositorio
- **`generador_datos.py`**: Script en Python para la simulación y estructuración de la base de datos histórica.
- **`datos_fisioterapia.csv`**: Dataset limpio utilizado para alimentar las métricas del dashboard.
- **`Dashboard_Fisioterapia.pbix`**: Reporte interactivo en Power BI con los casos de estudio desarrollados.

---

## 📊 Casos de Estudio Desarrollados en el Dashboard
1. **Caso 1 - Estacionalidad y Demanda:** Correlación entre meses pico y tipos de equipos afectados.
2. **Caso 2 - Estrategia Operativa (Reparar vs. Cambiar):** Análisis de placas electrónicas y acoplamiento de mantenimientos preventivos.
3. **Caso 3 - Concentración de Clientes (Pareto):** Identificación de cuentas VIP y análisis de dispersión (frecuencia vs. ticket promedio).
4. **Caso 4 - Crecimiento Histórico:** Evolución interanual y mix logístico (Taller vs. Terreno).
